=== A. Cubic Hermite (pos+vel samples, Eyes PosPoint.calculate) error bound on a circular orbit ===
  f(t)=r cos(nt): |err| <= h^4/384 * max|f''''| = r (n h)^4 / 384   (classic cubic-Hermite bound)
  Earth about Sun  r=1.496e+08 km  P= 365.250 d : step for 1 km error =     55.84 h ; for 0.1 km =    31.40 h ; samples/rev @1km =  157.0
  Mars about Sun   r=2.28e+08 km  P= 687.188 d : step for 1 km error =     94.56 h ; for 0.1 km =    53.18 h ; samples/rev @1km =  174.4
  Moon about Earth r=3.844e+05 km  P=  27.320 d : step for 1 km error =     18.55 h ; for 0.1 km =    10.43 h ; samples/rev @1km =   35.3
  ISS about Earth  r=6778 km  P=   0.064 d : step for 1 km error =      0.12 h ; for 0.1 km =     0.07 h ; samples/rev @1km =   12.9
  GEO              r=4.216e+04 km  P=   0.997 d : step for 1 km error =      1.18 h ; for 0.1 km =     0.66 h ; samples/rev @1km =   20.3
  numeric check Earth, h=2.33 d: max Hermite error = 1.000 km (bound 1 km)
  -> 'sample, then interpolate' (Cesium SampledPositionProperty w/ HermitePolynomialApproximation, Eyes Dynamo pos) is exact enough at hourly LEO / multi-day planetary steps; the file size is what drives step choice.
  Eyes lazily streams chunks (PointSet per interval) and unloads chunks idle >15 s -> a 100-year, 200-object catalog never sits in RAM at once.

=== B. TrailComponent adaptive sampling: angle threshold 0.05235987755 rad ===
  threshold = 3.00 deg -> circular orbit needs 120 points per revolution; bisection up to 20 iters; 4 points added per frame (amortized), width in px (widthMin..widthMax), alphaFade, dash, glow uniforms
  e=0: total turning of velocity vector over one rev is still 2*pi -> ~120 points, but spacing in *time* near periapsis shrinks by ~((1+e)/(1-e))^2 = 1.0x vs apoapsis
  e=0.2: total turning of velocity vector over one rev is still 2*pi -> ~120 points, but spacing in *time* near periapsis shrinks by ~((1+e)/(1-e))^2 = 2.2x vs apoapsis
  e=0.6: total turning of velocity vector over one rev is still 2*pi -> ~120 points, but spacing in *time* near periapsis shrinks by ~((1+e)/(1-e))^2 = 16.0x vs apoapsis
  e=0.9: total turning of velocity vector over one rev is still 2*pi -> ~120 points, but spacing in *time* near periapsis shrinks by ~((1+e)/(1-e))^2 = 361.0x vs apoapsis

=== C. Kepler solver in Pioneer (getEccentricAnomalyFromMeanAnomaly) ===
  Newton on g(E)=E-e sinE-M, start E0=M (E0=+-pi if e>=0.8), max 20 iters, stop when |dE|<0.00174532925 rad (=0.1 deg). Hyperbolic branch uses sinh/cosh with start ln(2|M|/e+1.8).
  0.1 deg tolerance at 1 AU is a position error of up to 261,098 km -> fine for pixels (1 px ~ 4.6e5 km at Mars-orbit zoom), NOT fine for mission design. Our optimize/ layer must use 1e-10-ish tolerances.
